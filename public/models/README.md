# City Pack models

The runtime GLB files in this folder are selected from the [Poly Pizza City Pack](https://poly.pizza/bundle/City-Pack-kJqRAIGsw0). Model textures are preserved, and runtime materials are converted to `MeshToonMaterial` for Inkville's illustrated lighting.

| Runtime file | Source model | Creator | License |
| --- | --- | --- | --- |
| `city-pack-cottage.glb` | Building Green | J-Toastie | CC BY |
| `city-pack-townhouse.glb` | Brown Building | J-Toastie | CC BY |
| `city-pack-apartment.glb` | Building Red | J-Toastie | CC BY |
| `city-pack-store.glb` | Pizza Corner | J-Toastie | CC BY |
| `city-pack-tree.glb` | Tree | Poly by Google | CC BY |
| `city-pack-car.glb` | Car | Quaternius | CC0 |
| `city-pack-pickup.glb` | Pickup Truck | Quaternius | CC0 |
| `city-pack-bus.glb` | Bus | Poly by Google | CC BY |

The City Pack page identifies the collection as a mix of CC BY and CC0 models. The model attributions above correspond to the assets used in-game. GLB files are bundled locally; no model downloads are required at runtime.
